# 독서 알림 정리 (영웅입지전 모드)

영웅입지전 모드 '독서 알림 정리'의 배포·소스 저장소입니다. 소스는 MIT-0 으로 공개합니다(LICENSE).

책을 들고 시간을 보내면 뜨는 알림창을 클릭 없이 화면 구석 로그(날짜와 함께 쌓이는 회색 글)로 바꿉니다.
- 책 진행도 25/50/75/100% 창(주인공): 창 대신 로그 한 줄. 경험치 등 보상은 그대로 들어옵니다.
- 책 보상 '아이템 획득' 창(주인공·동행): 자동으로 '확인'해 가방에 넣고 로그 한 줄.
- 약 보상 등 책이 아닌 아이템 창은 그대로 뜹니다.

## 받기·설치
- 받기: 오른쪽 **Releases** 의 최신 압축(zip)
- 설치 둘 중 하나
  - 압축을 풀고 `설치.cmd` 더블클릭(게임은 끈 채로). 지우기는 `제거.cmd`.
  - 영웅입지전 모드매니저 창에 압축을 끌어다 놓기. 모드매니저로 설치하면 새 버전을 '업데이트 확인' → '지금 업데이트'로 바로 받습니다.
- 게임 파일은 바꾸지 않습니다. 인터넷 전송 없음, 치트 기능 없음.

## 동작 방식
- 게임 함수에 끼어들기(후킹): `UI_FinishReadingUI.OpenUI`(독서 완료 창), `UI_ConfirmContributeUI.OpenUI`(아이템 획득 창), 책 진행 보상 함수 둘(책인지 표시만).
- 고정 주소나 난독화 이름을 코드에 박지 않습니다. 시작할 때 난독화되지 않은 이름과 기계어 모양(지문)으로 매번 찾고, 못 찾은 기능은 쉬고 원래 창이 뜹니다.
- 자세한 설명은 `src/reading.c` 맨 위 주석.

## 빌드
- Zig 0.14.1(clang·lld-link) 이 `.tools/zig-x86_64-windows-0.14.1/zig.exe` 에 있어야 합니다. Windows SDK·CRT 없이 빌드합니다.
- `python build.py` → `build/LOH_ReadingNotice.dll`, `build/entry/{version,winhttp,winmm,hid}.dll`(손 설치용 입구)
- `python package.py` → `dist/` 에 배포 압축(비밀번호 없음·1234 두 가지)
